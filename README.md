# Java projects

Java exercises from my first year, from the basics up to classes and objects.

| Folder | Topics |
|---|---|
| `introduction` | Input, output, expressions, string handling (age calculator, palindrome checker) |
| `conditions&loops` | Conditions and loops (Collatz conjecture, month lookup, sums) |
| `methods_recursion` | Methods and recursion (Fibonacci, quicksort, means) |
| `classes_objects` | Classes and objects, including a console version of **2048** |
| `object_lifecycle` | Object creation and lifecycles (shop and singer tasks) |
| `ObjectPracticeDemo` | References, null pointers and linked objects |
| `Coursework2` | Coursework: a research expedition model with team roles |

Each folder is a separate IntelliJ project. Open it and run the class with a `main` method.

My larger Java game, Pixel Adventure, has its own repo: [java-platformer](https://github.com/danzgeorg/java-platformer).
